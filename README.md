# Muralidharan Kumar — Portfolio

Personal portfolio site for Muralidharan Kumar, PhD — materials & additive manufacturing engineer
(laser powder bed fusion, metallurgy, mechanical testing, failure analysis, and ML for materials).

Static HTML/CSS/JS built on the [BootstrapMade "Personal"](https://bootstrapmade.com/personal-free-resume-bootstrap-template/) template.

## Pages

| File | Purpose |
| --- | --- |
| `index.html` | Landing / hero |
| `about.html` | Bio, focus areas, career strip |
| `resume.html` | Full CV — experience, education, skills, certifications, awards |
| `academics.html` | Publications, coursework, awards, conferences, teaching, service |
| `projects.html` | Research & publications showcase (filterable) |
| `contact.html` | Contact details |

## Local preview

Open the folder in VS Code and use the **Live Preview** extension
(`ms-vscode.live-server`, recommended in `.vscode/extensions.json`):
right-click `index.html` → **Show Preview**.

## Before publishing

- Add a headshot at `assets/img/murali.jpg` (the site falls back to a monogram
  placeholder until then).
- Find-and-replace `https://yourusername.github.io/itsmurliweb/` in the
  `<link rel="canonical">` and Open Graph / Twitter meta tags with the real
  deployment URL.
